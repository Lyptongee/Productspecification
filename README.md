# Product Specification Portal (starter)

A responsive, single-page product specification form built with HTML, CSS and vanilla JavaScript.

## Run locally
Open `index.html` in a modern browser.

## Publish with GitHub Pages
1. Create a GitHub repository (for example, `product-spec-portal`).
2. Upload `index.html` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then Save.
6. GitHub will provide the published website URL.

## Included in this starter
- Project and customer details
- Product category and product dimensions
- Optional drawing/image preview
- Add/remove technical specification rows
- Live summary panel
- Browser-local draft saving
- JSON data export
- Customer signature pad
- Print / Save as PDF

## Important limitations
This is a front-end prototype. Drafts are saved only in the current browser on the current device. There is no shared database, login, server-side storage, email sending, or multi-user access yet. The product categories and specification fields are starter examples and should be aligned with the actual workbook before operational use.
